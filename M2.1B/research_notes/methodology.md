# M2.1B — Research Methodology

**Date:** 2026-11-06.

## Approach

1. Identified central statutes relevant to tenant-landlord security-deposit disputes (TPA, ICA, SRA,
   Registration Act, MTA model, Limitation Act, Consumer Protection Act, IPC/BNS).
2. Enumerated all 36 States/UTs; classified each into MTA-adopter / TN/AP-model / rent-control (no cap) /
   TPA-only based on PRS, SRC-04 (Mithun Srivastava) and RentNiti state guides.
3. Extracted deposit caps, forums, and key sections from secondary sources; flagged unverified items.
4. Built provision-level inventory with stable IDs (TPA-xxx, MTA-xx, ST-xx, CC-x).
5. Produced state applicability table, temporal metadata recommendations, and evaluation dataset.

## Verification standard

- Official statute text preferred (India Code, state gazettes, MoHUA PDF).
- Where official text was blocked (MoHUA 403, India Code access issues), secondary sources used and
  flagged as `uncertain`/`unverified`.
- City-level customary deposit levels treated as market practice, not law.

## Limitations

- Research date 2026-11-06; laws change frequently. Re-verify before production use.
- Several state rent-statute deposit clauses unconfirmed (Telangana, West Bengal, Gujarat, Arunachal).
- Chandigarh extension contested.
